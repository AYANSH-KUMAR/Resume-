Ayansh Kumar Yadav - Animated Portfolio WebsiteThis is a responsive, dark-mode SPA (Single Page Application) portfolio for Ayansh Kumar Yadav. It features smooth section transitions, animated About and Contact cards, toggleable light/dark modes, and professional mobile/Desktop design.FeaturesSingle Page Navigation: Home, About, Services, and Contact sections with animated transitions (no full-page reloads).Modern Glassmorphism UI: Card-style sections with neon shadows, rounded borders, and clean alignment.Animated Content: Section entries use CSS 3D fade/slide animations for a professional look.Dark/Light Mode Toggle: Instantly switch the theme with a toggle button in the header.Responsive Design: Works great on mobile and desktop screens.Contact Form: Styled contact form with a modern submit button and info card.Folder Structure/
